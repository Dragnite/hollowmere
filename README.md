# Hollowmere: Echoes of the Delve

A single-file HTML5 canvas idle RPG. Everything (code, art, sound, fonts, translations) lives in `index.html`.

To update later, upload a new `index.html` over the old one and commit.

## Notes

- Saves use the browser's local storage so they belong to the player's browser and the site address (they do not sync between devices but you can export a save string). Use Settings > Save to export or import a backup.
- The game works offline once loaded. The optional online text-fill (Google Translate) only runs if the player leaves it on in Settings > Interface.
- Controls: keyboard and mouse, or an Xbox/standard controller (works in the Xbox browser). F1 or LT + Menu opens the help window.
